## Image Folder Guide

Place your wedding images in this folder with the exact filenames below.

Required files:

- `hero-main.jpg`
- `story-groom.jpg`
- `story-bride.jpg`
- `story-snap.jpg`
- `gallery/gallery-01.jpg`
- `gallery/gallery-02.jpg`
- `gallery/gallery-03.jpg`
- `gallery/gallery-04.jpg`
- `gallery/gallery-05.jpg`
- `gallery/gallery-06.jpg`
- `gallery/gallery-07.jpg`
- `gallery/gallery-08.jpg`

Recommended:

- Export JPGs around 1200px to 1600px on the long edge.
- Keep each file under about 500KB to 900KB if possible.
- Use the same crop ratio for gallery images for a cleaner layout.

If you want to use PNG or WebP instead, update the file extensions in `frame.html`.

Original high-resolution files are backed up in `images/originals/`.
